# ✈️ Destino Certo Turismo

Projeto de um site de turismo desenvolvido com **HTML, CSS, JavaScript, Bootstrap e jQuery**, apresentando destinos turísticos brasileiros, informações sobre pacotes de viagem e um formulário de contato.

## 📖 Sobre o Projeto

O **Destino Certo Turismo** é uma página web responsiva criada para divulgar destinos turísticos e pacotes de viagem. O site possui um layout moderno, carrossel de imagens, modo escuro, cartões de destinos e formulário de contato para interação com os visitantes.

## 🚀 Funcionalidades

* ✅ Navegação responsiva com Bootstrap
* ✅ Modo Escuro / Modo Claro
* ✅ Carrossel de banners
* ✅ Exibição de destinos turísticos
* ✅ Botão para mostrar/ocultar destinos
* ✅ Cards com informações e links externos
* ✅ Formulário de contato
* ✅ Rodapé com informações da empresa e redes sociais
* ✅ Layout adaptável para dispositivos móveis

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* jQuery
* Bootstrap 5
